# Distance Calculator

## Description

This program calculates the distance between two points.

The user enters the x and y values for two points. The program then calculates and displays the distance.

## How to Run

1. Run the FA1.py program.
2. Enter the value of x1.
3. Enter the value of y1.
4. Enter the value of x2.
5. Enter the value of y2.
6. The program will show the distance.

## Input

The program needs four values:

- x1
- y1
- x2
- y2

## Sample Output
```markdown
Enter x1: 2  
Enter y1: 3  
Enter x2: 7  
Enter y2: 8  
```
The distance between the two points is: 7.07
